PROJECT OVERVIEW
================

This is a complete, production-ready AI assistant for brand management,
featuring five core modules that handle your day-to-day responsibilities:

1. 📊 DATA PERFORMANCE ANALYSIS
   - Nielsen/IRI data analysis
   - Competitive benchmarking
   - Driver identification
   - Actionable recommendations

2. ✍️ CREATIVE BRIEF GENERATOR
   - Template-based brief creation
   - Strategic framework development
   - Agency-ready documentation
   - Multiple brief types supported

3. 🎨 BRAND POSITIONING WORKSHOP
   - Brand OS development
   - Positioning statement creation
   - Competitive differentiation
   - Strategic rationale

4. 💡 INNOVATION IDEATION
   - Concept generation
   - Packaging descriptions
   - Commercial viability assessment
   - Go-to-market strategies

5. 📑 POWERPOINT DECK GENERATOR
   - Presentation structure creation
   - Slide-by-slide content
   - Actual .pptx file generation
   - Template integration

QUICK START (3 STEPS)
=====================

1. Install Dependencies (2 minutes)
   $ pip install -r requirements.txt
   OR
   $ chmod +x setup.sh && ./setup.sh

2. Set API Key (30 seconds)
   $ export ANTHROPIC_API_KEY='your-key-here'
   OR edit .env file

3. Launch (10 seconds)
   $ streamlit run brand_manager_web.py

   Browser opens → Select module → Fill form → Generate!

SUPPORT & TROUBLESHOOTING
==========================

Common Issues:

"API key not found"
→ Check .env file or environment variable
→ Verify key is valid at console.anthropic.com

"Module not found"
→ Run: pip install -r requirements.txt
→ Check you're in correct Python environment

"Web interface won't load"
→ Ensure Streamlit installed
→ Try different port: --server.port 8502
→ Check no other apps using port 8501

"Slow responses"
→ Normal for complex requests (20-40 seconds)
→ Consider using async for batch processing
→ Cache common analyses locally

For detailed troubleshooting, see README.md
